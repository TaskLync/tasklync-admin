# TaskLync Admin

**The central platform for managing and operating TaskLync.**

TaskLync Admin is the internal dashboard used by the TaskLync team to manage users, professionals, bookings, verifications, payments, and other platform operations.

## 🌐 Platform

https://admin.tasklync.pk

## Admin Panel

TaskLync Admin provides tools for:

* Manage users and professionals
* Verify professional accounts
* Monitor and manage bookings
* Manage payments and refunds
* Handle disputes and reviews
* Manage the TaskLync waitlist
* View platform analytics
* Manage services and categories
* Manage admin accounts and settings

## Technology

TaskLync Admin is built using modern web technologies, including:

* Next.js
* React
* TypeScript
* Tailwind CSS
* PostgreSQL
* Redis
* Supabase
* Vercel

## Our Goal

The TaskLync Admin Panel gives our team a single place to operate, monitor, and grow the TaskLync platform efficiently.
